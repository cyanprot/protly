> **For Claude:** REQUIRED SUB-SKILL: Use execute-flow to implement this plan task-by-task.

**Goal:** Rename ig-translate to protly, give every surface the northprot ink-and-paper look, add a control-center
popup with usage cost and an options page with diagnostics, and make Alt+T work in any site's text box.

**Architecture:** The MV3 extension keeps its shape: unbundled ES-module content scripts on Instagram and Gmail, a

on demand with `chrome.scripting` after an adapter-first routing check.

**Tech Stack:** Chrome MV3, plain ES modules, node:test + jsdom 30.1.3, Python 3.14 unittest, esbuild 0.28.2
(new dev dependency), fontTools + brotli (woff2 subsetting), rsvg-convert (icon PNGs).

```js
export const ERRORS = {
  auth: 'API key missing or rejected. Check ~/.config/anthropic/api-key.',
  host: 'Native host not reachable. Run host/install.sh <extension id>, then reload the extension.',
  host_bug: 'The native host hit an error',
  spend_limit: 'Monthly API spend limit reached. Paused until the limit resets.',
  bad_request: 'The API rejected the request (check the model ids in Options)',
  stale: 'protly was reloaded or updated. Reload this tab.',
  timeout: 'The model took too long. Try again.',
  network: 'Network error. Check the connection and try again.',
  rate: 'Rate limited. Try again in a moment.',
  overloaded: 'The API is overloaded. Try again in a moment.',
  server: 'The API had a server error. Try again.',
  refused: 'The model declined this text.',
  truncated: 'The reply was cut off. Try Opus or a shorter text.',
  parse: 'The reply was not readable. Try again.',
};
// Kinds worth a page toast (once per text), not only an inline message. Replaces bannerFor's list.
export const GLOBAL_KINDS = new Set(['auth', 'host', 'host_bug', 'spend_limit', 'bad_request', 'stale']);
export function errorText(e) {
  const base = ERRORS[e?.kind];
  if (!base) return String(e?.message || e || 'Unknown error');
  return e.kind === 'host_bug' || e.kind === 'bad_request' ? `${base}: ${e.message}` : base;
```

### `src/ui/theme.js` (Sprint 2)

- `parseColor(css)` -> `[r, g, b, a]` from `rgb()`/`rgba()` strings, `null` otherwise.
- `luminance([r, g, b])` -> WCAG relative luminance 0..1.
- `pickTheme(doc, from?)` -> `'light' | 'dark'`: when the optional Element `from` is given, the first of `from` and its
  ancestors (crossing shadow roots via `getRootNode().host`) whose computed `background-color` has alpha >= 0.5 decides;
  otherwise (no `from`, or no such ancestor) the first non-transparent computed `background-color` of `doc.body`, then
  `doc.documentElement`; none -> `'light'`; luminance < 0.4 -> `'dark'`.
- `bindTheme(el, doc = el.ownerDocument)` sets `el.dataset.plTheme` from `el`'s surroundings: `pickTheme(doc, from)` with
  `from` = the parent of `el`'s shadow host when `el` lives in a shadow root, else `el.parentElement` (null while not yet
  in the page -> the body rule). It does so now and, per element, on every `class`/`style` attribute change of `html`
  and `body` (one shared MutationObserver per document; detached elements are dropped), returns an unbind function.
  So a card inside a white Gmail compose on a dark page is light; toast and panel hosts sit in `body` and get the body rule.

### `src/ui/fonts.js` (Sprint 2)

`addFonts(doc, { regular, medium })`: each source is a URL string or an `ArrayBuffer`/`Uint8Array`. Creates
`new FontFace('protly-mono', src, { weight: '400' | '500' })` (a string becomes `url("...")`), `doc.fonts.add(face)`,
`face.load().catch(() => {})`. Idempotent per document (module-level `WeakSet`); a no-op when `doc.fonts` is missing (jsdom). Instagram and Gmail
pass bytes from `fetchFonts(chrome.runtime.getURL)` (also exported: `FONT_FILES`), read by the content script, because a
`url()` source is fetched by the page and can be blocked by its CSP `font-src`. The generic bundle passes the inlined
bytes.

### `src/ui/toast.js` (Sprint 2)

`showToast(text, { transient = false, error = false, doc = document } = {})`. One fixed top-right container (shadow
host `div.pl-toasts`, open shadow root) per document. Non-transient toasts are shown once per text (module-level
`Set`), transient ones auto-dismiss after 4000 ms and may repeat. Click dismisses. Exported `_resetToasts()` clears the
dedupe set for tests. Replaces `showBanner` everywhere; text no longer carries an `ig-translate:` prefix (the toast shows

**Step 3: Write the ID script**

`scripts/extension-id.mjs`:

```js
import { createHash } from 'node:crypto';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';

// Chrome's extension ID: SHA-256 of the DER public key, first 16 bytes, each hex digit 0-f mapped to a-p.
export function extensionId(keyB64) {
  const hex = createHash('sha256').update(Buffer.from(keyB64, 'base64')).digest('hex').slice(0, 32);
  return [...hex].map((c) => String.fromCharCode(97 + parseInt(c, 16))).join('');
}

// Run directly: print the ID that manifest.json's key pins.
if (process.argv[1] === fileURLToPath(import.meta.url)) {
  const m = JSON.parse(readFileSync(new URL('../manifest.json', import.meta.url), 'utf8'));
  if (!m.key) { console.error('manifest.json has no key'); process.exit(1); }
  console.log(extensionId(m.key));
}
```

```python
#!/usr/bin/python3
"""Build the protly-mono woff2 subsets (Latin) from the system JetBrains Mono OTFs.

Run: python3 -I scripts/build-fonts.py
Output: src/ui/fonts/protly-mono-400.woff2 and -500.woff2, committed. Re-run only when the subset changes.
"""
import shutil
from pathlib import Path

from fontTools import subset
from fontTools.ttLib import TTFont

SRC = Path('/usr/share/fonts/jetbrains-mono-fonts')
LICENSE = Path('/usr/share/licenses/jetbrains-mono-fonts/OFL.txt')
OUT = Path(__file__).resolve().parent.parent / 'src' / 'ui' / 'fonts'
FAMILY = 'protly-mono'
# Basic Latin, Latin-1, general punctuation (dashes, quotes, bullet, ellipsis), arrows, dot operator.
UNICODES = [*range(0x20, 0x7F), *range(0xA0, 0x100), *range(0x2010, 0x2028), *range(0x2190, 0x2194), 0x22C5]


def build(weight, style):
    opts = subset.Options()
    opts.flavor = 'woff2'
    opts.layout_features = []  # no ligatures: "->" stays two characters in protly's UI
    opts.name_IDs = ['*']
    opts.notdef_outline = True
    font = TTFont(SRC / f'JetBrainsMono-{style}.otf')
    sub = subset.Subsetter(opts)
    sub.populate(unicodes=UNICODES)
    sub.subset(font)
    name = font['name']
    name.removeNames(nameID=16)
    name.removeNames(nameID=17)
    for rec in name.names:
        if rec.nameID == 1:
            rec.string = FAMILY
        elif rec.nameID == 2:
            rec.string = 'Regular'  # one family, two weights: CSS picks by weight
        elif rec.nameID == 4:
            rec.string = f'{FAMILY} {style}'
        elif rec.nameID == 6:
            rec.string = f'{FAMILY}-{style}'
    font.flavor = 'woff2'
    out = OUT / f'{FAMILY}-{weight}.woff2'
    font.save(out)
    print(f'{out.name}: {out.stat().st_size} bytes')


if __name__ == '__main__':
    OUT.mkdir(parents=True, exist_ok=True)
    build('400', 'Regular')
    build('500', 'Medium')
    shutil.copyfile(LICENSE, OUT / 'OFL.txt')
```

on 2026-10-28 gave 9872 and 10264).

**Step 3: Write the build script**

Same recipe as `~/Document/northprot-brand-assets/src/build_svg.py` and its `svg/favicon.svg` (the `n` there sits at
`translate(200 775)`, its bounding box centred in a 1000 x 1000 paper square). The `p` here is centred the same way by

`scripts/build-icons.py`:

```python
#!/usr/bin/python3
"""Build protly's icon (outlined p) and wordmark (outlined protly) from JetBrains Mono Medium.

Run: python3 -I scripts/build-icons.py
Output (committed): icons/p.svg, icons/wordmark.svg, icons/icon-{16,32,48,128}.png (PNGs via rsvg-convert).
Deliberate departure from BRAND.md 5.3: protly is a product, not the northprot mark, so it gets its own p.
"""
import subprocess
from pathlib import Path

from fontTools.pens.boundsPen import BoundsPen
from fontTools.pens.svgPathPen import SVGPathPen
from fontTools.ttLib import TTFont

FONT = '/usr/share/fonts/jetbrains-mono-fonts/JetBrainsMono-Medium.otf'
OUT = Path(__file__).resolve().parent.parent / 'icons'
PAPER, INK = '#F5F0E6', '#1A1F2E'
SIZES = (16, 32, 48, 128)

font = TTFont(FONT)
glyphs = font.getGlyphSet()
cmap = font.getBestCmap()


def outline(ch):
    g = glyphs[cmap[ord(ch)]]
    pen = SVGPathPen(glyphs)
    g.draw(pen)
    bounds = BoundsPen(glyphs)
    g.draw(bounds)
    return pen.getCommands(), bounds.bounds, g.width


def icon_svg():
    d, (xmin, ymin, xmax, ymax), _ = outline('p')
    tx = 500 - (xmin + xmax) / 2
    ty = 500 + (ymin + ymax) / 2  # font y is up; scale(1 -1) flips it
    return (f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 1000 1000" fill="{INK}">\n'
            f'  <rect width="1000" height="1000" fill="{PAPER}"/>\n'
            f'  <path transform="translate({tx} {ty}) scale(1 -1)" d="{d}"/>\n'
            '</svg>\n')


def wordmark_svg(text='protly'):
    cap = font['OS/2'].sCapHeight
    descent = font['hhea'].descent  # negative
    paths, x = [], 0
    for ch in text:
        d, _, advance = outline(ch)
        paths.append(f'  <path transform="translate({x} 0) scale(1 -1)" d="{d}"/>')
        x += advance
    # currentColor: pages theme it (inline it, or use it as a CSS mask over var(--pl-fg)).
    return (f'<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 {-cap} {x} {cap - descent}" fill="currentColor">\n'
            + '\n'.join(paths) + '\n</svg>\n')


if __name__ == '__main__':
    OUT.mkdir(exist_ok=True)
    (OUT / 'p.svg').write_text(icon_svg())
    (OUT / 'wordmark.svg').write_text(wordmark_svg())
    for s in SIZES:
        subprocess.run(['rsvg-convert', '-w', str(s), '-h', str(s), str(OUT / 'p.svg'), '-o', str(OUT / f'icon-{s}.png')],
                       check=True)
    print('built', ', '.join(p.name for p in sorted(OUT.iterdir())))
```

```js
// Light or dark for protly's own UI, from the page's effective background. Popup and options use
// prefers-color-scheme instead (they have no page to match).

export function parseColor(css) {
  const m = /^rgba?\(\s*([\d.]+)[\s,]+([\d.]+)[\s,]+([\d.]+)(?:\s*[,/]\s*([\d.]+%?))?\s*\)$/.exec((css || '').trim());
  if (!m) return null;
  const a = m[4] === undefined ? 1 : m[4].endsWith('%') ? parseFloat(m[4]) / 100 : parseFloat(m[4]);
  return [Number(m[1]), Number(m[2]), Number(m[3]), a];
}

export function luminance([r, g, b]) {
  const lin = (c) => { const s = c / 255; return s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4; };
  return 0.2126 * lin(r) + 0.7152 * lin(g) + 0.0722 * lin(b);
}

export function pickTheme(doc) {
  const win = doc.defaultView;
  for (const el of [doc.body, doc.documentElement]) {
    if (!el || !win) continue;
    const c = parseColor(win.getComputedStyle(el).backgroundColor);
    if (c && c[3] > 0) return luminance(c) < 0.4 ? 'dark' : 'light';
  }
  return 'light';
}

const bound = new WeakMap(); // document -> Set of elements kept in sync

// Sets el.dataset.plTheme now and whenever html or body change class or style. Returns an unbind function.
export function bindTheme(el, doc = el.ownerDocument) {
  el.dataset.plTheme = pickTheme(doc);
  let set = bound.get(doc);
  if (!set) {
    set = new Set();
    bound.set(doc, set);
    const mo = new doc.defaultView.MutationObserver(() => {
      const t = pickTheme(doc);
      for (const e of set) e.dataset.plTheme = t;
    });
    const opts = { attributes: true, attributeFilter: ['class', 'style'] };
    mo.observe(doc.documentElement, opts);
    if (doc.body) mo.observe(doc.body, opts);
  }
  set.add(el);
  return () => set.delete(el);
}
```

```js
// Chrome ignores @font-face inside shadow roots, but a FontFace added to document.fonts is visible to them.
export const FONT_FILES = {
  regular: 'src/ui/fonts/protly-mono-400.woff2',
  medium: 'src/ui/fonts/protly-mono-500.woff2',
};

const done = new WeakSet();

// regular / medium: a URL string or the font bytes (ArrayBuffer or Uint8Array).
export function addFonts(doc, { regular, medium }) {
  if (!doc.fonts || done.has(doc)) return; // jsdom has no doc.fonts
  done.add(doc);
  const FontFaceImpl = doc.defaultView?.FontFace ?? globalThis.FontFace;
  for (const [src, weight] of [[regular, '400'], [medium, '500']]) {
    if (!src) continue;
    const face = new FontFaceImpl('protly-mono', typeof src === 'string' ? `url("${src}")` : src,
      { weight, style: 'normal', display: 'swap' });
    doc.fonts.add(face);
    face.load().catch(() => {}); // a failed load leaves the monospace fallback
  }
}

// Instagram and Gmail: the bundled files as bytes, read by the content script, never by the page (CSP font-src).
export async function fetchFonts(getURL, fetchImpl = fetch) {
  const get = async (path) => {
    const r = await fetchImpl(getURL(path));
    if (!r.ok) throw new Error(`font ${path}: HTTP ${r.status}`);
    return r.arrayBuffer();
  };
  const [regular, medium] = await Promise.all([get(FONT_FILES.regular), get(FONT_FILES.medium)]);
  return { regular, medium };
}
```

```js
import { TOAST_CSS } from './toast.css.js';
import { bindTheme } from './theme.js';

const TRANSIENT_MS = 4000;
const shown = new Set(); // persistent toast texts already shown on this page
const lists = new WeakMap(); // document -> toast list element

export function _resetToasts() { shown.clear(); }

function listFor(doc) {
  let list = lists.get(doc);
  if (list?.isConnected) return list;
  const host = doc.createElement('div');
  host.className = 'pl-toasts';
  const root = host.attachShadow({ mode: 'open' });
  const style = doc.createElement('style');
  style.textContent = TOKENS + BASE + TOAST_CSS;
  list = doc.createElement('div');
  list.className = 'pl-root list';
  root.append(style, list);
  bindTheme(list, doc);
  (doc.body || doc.documentElement).appendChild(host);
  lists.set(doc, list);
  return list;
}

// transient: auto-dismiss and allow repeats (per-keypress feedback). Otherwise once per text per page.
export function showToast(text, { transient = false, error = false, doc = document } = {}) {
  if (shown.has(text)) return null;
  if (!transient) shown.add(text);
  const t = doc.createElement('div');
  t.className = error ? 'toast err' : 'toast';
  t.title = 'Click to dismiss';
  const label = doc.createElement('span');
  label.className = 'label';
  label.textContent = 'protly';
  const msg = doc.createElement('span');
  msg.className = 'msg';
  msg.textContent = text;
  t.append(label, msg);
  t.addEventListener('click', () => t.remove());
  listFor(doc).appendChild(t);
  if (transient) setTimeout(() => t.remove(), TRANSIENT_MS);
  return t;
}
```

```js
import { TOKENS, BASE } from './tokens.css.js';
import { CARD_CSS } from './card.css.js';
import { bindTheme } from './theme.js';
import { LANG_NAMES, langName } from '../lib/lang.js';

export const modelLabel = (m) => (m && m.includes('opus') ? 'Opus' : 'Sonnet');

const GAP = 6; // px between the anchor rect and a floating card

// place: { before: Element } | { after: Element } | { float: () => DOMRect }. See the plan's shared contracts.
export function createCard({ doc = document, place }) {
  const win = doc.defaultView;
  const host = doc.createElement('div');
  host.className = 'pl-card';
  const shadow = host.attachShadow({ mode: 'open' });
  const style = doc.createElement('style');
  style.textContent = TOKENS + BASE + CARD_CSS;
  const root = doc.createElement('div');
  root.className = 'pl-root';
  root.setAttribute('role', 'status');
  root.setAttribute('aria-live', 'polite');
  shadow.append(style, root);
  let unbindTheme = null;

  const el = (tag, cls, text) => {
    const e = doc.createElement(tag);
    if (cls) e.className = cls;
    if (text != null) e.textContent = text;
    return e;
  };
  const button = ({ label, onClick }) => {
    const b = el('button', null, label);
    b.type = 'button';
    b.addEventListener('mousedown', (e) => e.preventDefault()); // keep focus in the composer or text box
    b.addEventListener('click', (e) => { e.preventDefault(); e.stopPropagation(); onClick(e); });
    return b;
  };
  const chip = (lang, onLang) => {
    const sel = el('select', 'pl-chip');
    sel.title = 'Change target language';
    const codes = Object.keys(LANG_NAMES).filter((c) => c !== 'ko');
    if (!codes.includes(lang)) codes.unshift(lang); // a partner language outside the list
    for (const c of codes) {
      const o = el('option', null, langName(c));
      o.value = c;
      sel.appendChild(o);
    }
    sel.value = lang;
    sel.addEventListener('change', () => onLang(sel.value));
    return sel;
  };

  function placeFloat() {
    const r = place.float();
    const box = host.getBoundingClientRect();
    const h = box.height || 0;
    const w = box.width || 0;
    const below = r.bottom + GAP;
    const top = below + h > win.innerHeight && r.top - GAP - h >= 0 ? r.top - GAP - h : below;
    const left = Math.max(GAP, Math.min(r.left, win.innerWidth - w - GAP));
    host.style.top = `${Math.round(top)}px`;
    host.style.left = `${Math.round(left)}px`;
  }

  function insert() {
    if (host.isConnected) return;
    if (place.before) place.before.before(host);
    else if (place.after) place.after.after(host);
    else {
      host.style.position = 'fixed';
      host.style.zIndex = '2147483646';
      (doc.body || doc.documentElement).appendChild(host);
      win.addEventListener('scroll', placeFloat, true);
      win.addEventListener('resize', placeFloat);
    }
    if (!place.float) host.style.display = 'block';
    unbindTheme = bindTheme(root, doc);
  }

  function render(nodes, { error = false } = {}) {
    insert();
    root.classList.toggle('err', error);
    root.replaceChildren(...nodes);
    if (place.float) placeFloat();
  }

  const trailing = (lang, onLang, actions, hints) => [
    ...(lang && onLang ? [chip(lang, onLang)] : []),
    ...actions.map(button),
    ...(hints ? [el('span', 'hints', hints)] : []),
  ];

  return {
    host,
    // text without trailing dots: the card animates them.
    working(text, { onCancel } = {}) {
      render([el('span', 'msg dots', text.replace(/(\.\.\.|…)$/, '')), ...(onCancel ? [button({ label: 'Cancel', onClick: onCancel })] : [])]);
    },
    preview({ text, model, lang, onLang, actions = [], hints = '' }) {
      render([el('span', 'msg', text), ...(model ? [el('span', 'model', modelLabel(model))] : []), ...trailing(lang, onLang, actions, hints)]);
    },
    message(text, { actions = [], error = false, lang, onLang } = {}) {
      render([el('span', 'msg', text), ...trailing(lang, onLang, actions, '')], { error });
    },
    hide() {
      host.remove();
      unbindTheme?.();
      unbindTheme = null;
      if (place.float) {
        win.removeEventListener('scroll', placeFloat, true);
        win.removeEventListener('resize', placeFloat);
      }
    },
    isOpen: () => host.isConnected,
  };
}
```

```js
// Translate button and Alt+T.
export function translate(body) {
  const s = stateOf(body);
  if (s.mode === 'translating') return;
  const nodes = userNodes(body);
  const text = nodesToText(nodes).trim();
  if (s.mode === 'preview') {
    if (norm(text) === norm(s.shown)) return; // nothing new to translate
    // Polish only starts from idle, so Undo always goes back to the original draft.
    if (!hasHangul(text)) {
      return showError(body, s, flags.polish
        ? 'No Korean text to translate. To polish this English, press Undo first.'
        : 'No Korean text to translate. Use the picker or Opus to translate the original again.');
    }
    // A new Korean draft replaced the preview. The body holds it, so the older Korean is not needed for Undo.
    Object.assign(s, { mode: 'idle', saved: null });
  }
  let opts;
  if (hasHangul(text)) {
    // The prefix ("ru: ...") is a one-off override; the saved nodes keep it, so Undo brings it back.
    const p = parseLangPrefix(text);
    opts = { kind: 'translate', korean: p.text, profile: 'email', lang: p.lang ?? 'auto' };
  } else if (flags.polish && /\p{L}/u.test(text)) {
    opts = { kind: 'polish', korean: text, profile: 'email' };
  } else {
    return say(body, s, flags.polish
      ? 'Nothing to polish.'
      : 'No Korean text to translate. Turn on Polish English in the toolbar popup to polish English drafts.', { error: true });
  }
  if (hasMedia(nodes)) {
    const verb = opts.kind === 'polish' ? 'Polish' : 'Translate';
    return say(body, s, `The draft contains images. ${verb} the text before adding images.`, { error: true });
  }
  return request(body, opts);
}

// Picker and Opus in preview: same source and kind, other language or model.
function retranslate(body, { lang, profile, force = false }) {
  const s = stateOf(body);
  if (s.mode !== 'preview') return;
  const opts = { kind: s.kind, korean: s.korean, profile: profile ?? s.profile, lang: lang ?? s.lang };
  if (!force && norm(nodesToText(userNodes(body))) !== norm(s.shown)) {
    return say(body, s, 'You edited the translation. Translating again replaces your edit.', {
      actions: [
        act('Replace anyway', () => retranslate(body, { ...opts, force: true })),
        act('Keep my edit', () => showPreview(body, s)),
        act('Undo', () => undo(body)),
      ],
    });
  }
  return request(body, opts);
}

export function undo(body) {
  const s = stateOf(body);
  if (s.saved) replaceUserNodes(body, s.saved);
  Object.assign(s, { mode: 'idle', saved: null, kind: 'translate', korean: null, shown: null, lang: 'auto', profile: 'email', last: null });
  s.reqId++; // drop any result still in flight
  hideNote(s);
}

// Esc in a compose body: undo a preview or a translation in flight. False when there is nothing to undo.
export function escape(body) {
  const s = states.get(body);
  if (!s || s.mode === 'idle') return false;
  undo(body);
  return true;
}

function cancel(body, reqId, prevMode) {
  const s = stateOf(body);
  if (s.reqId !== reqId || s.mode !== 'translating') return;
  s.reqId++; // the result, when it arrives, is dropped
  s.mode = prevMode;
  if (prevMode === 'preview') showPreview(body, s); else hideNote(s);
}

// The thread for an inline reply; a new compose window has none.
function threadContext(body) {
  const root = document.querySelector('[role="main"]');
  if (body.closest('[role="dialog"]') || !root) return [];
  const viewer = findViewerEmail(document);
  if (!viewer && !viewerWarned) {
    viewerWarned = true;
    console.warn('[protly] Gmail account email not found; every thread message counts as from the other side');
  }
  return readThread(root, viewer);
}

async function request(body, { kind = 'translate', korean, profile, lang }) {
  const s = stateOf(body);
  const prevMode = s.mode;
  const expected = nodesToText(userNodes(body)); // what the body must still hold when the result lands
  const reqId = ++s.reqId;
  s.mode = 'translating';
  const polish = kind === 'polish';
  const verb = polish ? 'Polishing' : 'Translating';
  cardOf(body, s).working(profile === 'hard' ? `${verb} with Opus` : verb, { onCancel: () => cancel(body, reqId, prevMode) });
  try {
    // Polish takes no thread context: one draft does not need it.
    const r = polish
      ? await ask({ type: 'polish', text: korean, profile })
      : await ask({ type: 'email', context: threadContext(body), korean, profile, lang });
    if (reqId !== s.reqId || !body.isConnected) return;
    s.mode = prevMode;
    // The draft changed while translating (the user kept typing): never overwrite it.
    if (norm(nodesToText(userNodes(body))) !== norm(expected)) {
      return showError(body, s, 'The draft changed while translating, so the translation was dropped.');
    }
    const removed = replaceUserNodes(body, textToNodes(document, r.translation));
    if (norm(nodesToText(userNodes(body))) !== norm(r.translation)) {
      replaceUserNodes(body, removed);
      return showError(body, s, 'Could not write the translation into the email. Your draft is back as it was.');
    }
    if (prevMode !== 'preview') s.saved = removed; // first result: keep the original draft nodes for Undo
    // The polish result carries no lang, so keep the current one.
    Object.assign(s, { mode: 'preview', kind, korean, shown: r.translation, lang: r.lang ?? s.lang, profile, last: r });
    showPreview(body, s);
  } catch (e) {
    if (reqId !== s.reqId) return;
    s.mode = prevMode;
    showError(body, s, `${polish ? 'Polish' : 'Translation'} failed: ${errorText(e)}`);
  }
}
```

```js
// Global toggles set from the toolbar popup. Mutable on purpose: tests set flags.polish directly.
// Cached here because Enter has to be blocked synchronously, before a storage read could return.
export const DEFAULT_SITES = { instagram: true, gmail: true };
export const flags = { polish: false, sites: { ...DEFAULT_SITES } };

let ready = null;

function apply(values) {
  if ('polish' in values) flags.polish = values.polish === true;
  if ('sites' in values) flags.sites = { ...DEFAULT_SITES, ...(values.sites || {}) };
}

// Resolves once the stored values are in; later changes keep arriving through storage.onChanged.
export function watchFlags() {
  ready ??= (async () => {
    chrome.storage.onChanged.addListener((changes, area) => {
      if (area !== 'local') return;
      const picked = {};
      for (const k of ['polish', 'sites']) if (k in changes) picked[k] = changes[k].newValue;
      apply(picked);
```

```js
// Token usage and cost, recorded from every 2xx API body (see callClaude's onUsage).
// Prices in US$ per million tokens, checked 2026-10-28 on https://platform.claude.com/docs/en/about-claude/pricing.
export const PRICES = {
  'claude-sonnet-5-5': { input: 2, output: 10, cache_read: 0.1, cache_5m: 2.5, cache_1h: 4 },
  'claude-opus-5-5': { input: 4, output: 20, cache_read: 0.2, cache_5m: 5, cache_1h: 8 },
};
export const KEEP_DAYS = 62;
const FIELDS = ['input', 'output', 'cache_read', 'cache_5m', 'cache_1h'];
const DAY_MS = 24 * 60 * 60 * 1000;
const count = (v) => (Number.isFinite(v) && v > 0 ? v : 0);

export function tokensOf(body) {
  const u = body?.usage || {};
  const split = u.cache_creation;
  const hasSplit = split && (typeof split.ephemeral_5m_input_tokens === 'number'
    || typeof split.ephemeral_1h_input_tokens === 'number');
  return {
    input: count(u.input_tokens),
    output: count(u.output_tokens),
    cache_read: count(u.cache_read_input_tokens),
    // No breakdown: count every cache write at the 5m rate.
    cache_5m: hasSplit ? count(split.ephemeral_5m_input_tokens) : count(u.cache_creation_input_tokens),
    cache_1h: hasSplit ? count(split.ephemeral_1h_input_tokens) : 0,
  };
}

// Exact id, or a dated variant of a known id ("claude-opus-5-5-20261001").
function priceFor(model) {
  if (typeof model !== 'string') return null;
  if (PRICES[model]) return PRICES[model];
  const base = Object.keys(PRICES).find((k) => model.startsWith(`${k}-`));
  return base ? PRICES[base] : null;
}

// US$ for one usage entry, or null when the model has no price.
export function costOf(entry, model) {
  const p = priceFor(model);
  if (!p) return null;
  return FIELDS.reduce((sum, f) => sum + (count(entry?.[f]) * p[f]) / 1e6, 0);
}

export function localDate(ms) {
  const d = new Date(ms);
  const pad = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
}

function prune(usage, now) {
  const cutoff = localDate(now - KEEP_DAYS * DAY_MS);
  for (const day of Object.keys(usage)) if (day < cutoff) delete usage[day];
}

// get() returns the stored usage object (or undefined); set(usage) stores it.
// Writes run one at a time so concurrent API calls never lose an increment.
export function createUsageRecorder({ get, set, now = Date.now }) {
  let chain = Promise.resolve();
  function record(body) {
    const model = typeof body?.model === 'string' && body.model ? body.model : 'unknown';
    const tokens = tokensOf(body);
    chain = chain.then(async () => {
      const usage = (await get()) || {};
      const t = now();
      const day = (usage[localDate(t)] ??= {});
      const e = (day[model] ??= { calls: 0, input: 0, output: 0, cache_read: 0, cache_5m: 0, cache_1h: 0 });
      e.calls += 1;
      for (const f of FIELDS) e[f] = count(e[f]) + tokens[f];
      prune(usage, t);
      await set(usage);
    }).catch((err) => console.warn('[protly] usage write failed', err));
    return chain;
  }
  return { record };
}

// { today, month } in US$ (local calendar), unpriced: a model this month had no price.
export function summarize(usage, now) {
  const today = localDate(now);
  const month = today.slice(0, 8); // "YYYY-MM-"
  const out = { today: 0, month: 0, unpriced: false };
  for (const [day, models] of Object.entries(usage || {})) {
    if (!day.startsWith(month)) continue;
    for (const [model, entry] of Object.entries(models)) {
      const c = costOf(entry, model);
      if (c == null) { if (entry?.calls) out.unpriced = true; continue; }
      out.month += c;
      if (day === today) out.today += c;
    }
  }
  return out;
}

export function formatUsd(n, unpriced = false) {
  const s = n > 0 && n < 0.005 ? '<$0.01' : `$${n.toFixed(2)}`;
  return unpriced ? `${s} ?` : s;
}
```

```js
const RESTRICTED = [
  /^chrome:/, /^chrome-extension:/, /^edge:/, /^about:/, /^view-source:/, /^devtools:/,
  /^https:\/\/chrome\.google\.com\/webstore/, /^https:\/\/chromewebstore\.google\.com/,

const UNAVAILABLE = { state: 'unavailable', text: 'Unavailable here' };
// Sprint 4 changes this to 'Alt+T ready' when the any-site path lands.
export const GENERIC_TEXT = 'Not active on this site';

const SITES = { 'www.instagram.com': ['instagram', 'Instagram'], 'mail.google.com': ['gmail', 'Gmail'] };

// The popup's one-line status for the active tab. badge: { text, reason } from the badge store, or null.
export function statusFor({ url, sites = DEFAULT_SITES, badge = null }) {
  if (!url || RESTRICTED.some((r) => r.test(url)) || !/^https?:/.test(url)) return UNAVAILABLE;
  if (badge?.text) return { state: 'problem', text: badge.reason ? `Problem: ${badge.reason}` : 'Problem on this page' };
  let host;
  try { host = new URL(url).hostname; } catch { return UNAVAILABLE; }
  const site = SITES[host];
  if (site) {
    const [key, name] = site;
    return sites[key] !== false ? { state: key, text: `${name}: active` } : { state: 'site-off', text: `${name}: off` };
  }
  return { state: 'generic', text: GENERIC_TEXT };
}
```

`src/lib/native.js` (whole file):

```js
import { ApiError } from './api.js';

export const HOST_NAME = 'com.northprot.protly';

// connect() returns a Port-like object: { postMessage, onMessage.addListener, onDisconnect.addListener }.
// lastError() returns why a port closed (chrome.runtime.lastError?.message), read inside onDisconnect.
// The returned transport(body) resolves { status, retry_after, body }; transport.ping() resolves
// { ok, key_present, workspace_header } from the host without calling the API.
export function createNativeTransport(connect, lastError = () => undefined, timeoutMs = 270000, pingTimeoutMs = 5000) {
  let conn = null; // { port, pending: Map<id, {resolve, reject, timer}> }
  let nextId = 1;

  function open() {
    const port = connect();
    const c = { port, pending: new Map() };
    port.onMessage.addListener((msg) => {
      const p = c.pending.get(msg?.id);
      if (!p) return;
      c.pending.delete(msg.id);
      clearTimeout(p.timer);
      p.resolve(msg.ping ? { ping: msg.ping } : { status: msg.status, retry_after: msg.retry_after ?? null, body: msg.body });
    });
    port.onDisconnect.addListener(() => {
      const reason = lastError() || 'native host disconnected';
      if (conn === c) conn = null;
      for (const p of c.pending.values()) { clearTimeout(p.timer); p.reject(new ApiError('host', reason)); }
      c.pending.clear();
    });
    return c;
  }

  function send(payload, ms) {
    return new Promise((resolve, reject) => {
      let c;
      try {
        c = conn || (conn = open());
      } catch (e) {
        reject(new ApiError('host', String(e?.message || e)));
        return;
      }
      const id = nextId++;
      const timer = setTimeout(() => {
        if (c.pending.delete(id)) reject(new ApiError('timeout', 'native host timed out'));
      }, ms);
      c.pending.set(id, { resolve, reject, timer });
      try {
        c.port.postMessage({ id, ...payload });
      } catch (e) {
        c.pending.delete(id);
        clearTimeout(timer);
        if (conn === c) conn = null;
        reject(new ApiError('host', String(e?.message || e)));
      }
    });
  }

  const transport = (body) => send({ body }, timeoutMs);
  transport.ping = async () => {
    const r = await send({ ping: true }, pingTimeoutMs);
    if (!r.ping) throw new ApiError('host_bug', 'the native host does not answer ping; re-run host/install.sh <extension id>');
    return r.ping;
  };
  return transport;
}
```

```js
// Korean IME helpers. A shortcut or a message carries no composition state, and the last syllable of a Korean
// composition is not in the box until the composition ends.

// One animation frame (a timer when there is none, as in node tests).
export const nextFrame = () => new Promise((r) => {
  if (typeof requestAnimationFrame === 'function') requestAnimationFrame(() => r());
  else setTimeout(r, 16);
});

// Blurring ends any open composition (the browser commits it); refocus and put the caret back.
export function commitByRefocus(el) {
  const doc = el.ownerDocument;
  let restore = () => {};
  if (el.tagName === 'TEXTAREA' || el.tagName === 'INPUT') {
    let start = null;
    let end = null;
    try { start = el.selectionStart; end = el.selectionEnd; } catch {} // email inputs have no selection API
    restore = () => { if (start != null) { try { el.setSelectionRange(start, end); } catch {} } };
  } else {
    const sel = doc.getSelection();
    const range = sel && sel.rangeCount ? sel.getRangeAt(0).cloneRange() : null;
    restore = () => {
      if (!range) return;
      const s = doc.getSelection();
      s.removeAllRanges();
      s.addRange(range);
    };
  }
  el.blur();
  el.focus();
  restore();
}

// Waits until no composition is open in el: at once when composing is false, else until compositionend or the
// timeout (then commitByRefocus), plus one frame so the committed text lands.
export async function settleComposition(el, { composing = false, timeoutMs = 500 } = {}) {
  if (composing) {
    await new Promise((resolve) => {
      let timer = null;
      const done = (timedOut) => {
        clearTimeout(timer);
        el.removeEventListener('compositionend', onEnd);
        if (timedOut) commitByRefocus(el);
        resolve();
      };
      const onEnd = () => done(false);
      timer = setTimeout(() => done(true), timeoutMs);
      el.addEventListener('compositionend', onEnd);
    });
  }
  await nextFrame();
}
```

```js
import { settleComposition } from './ime.js';

// Adapter side of Alt+T routing. owner() returns the adapter's focused box or null. When it owns the box the
// listener answers { handled: true } at once, then waits for any open IME composition and calls run(box).
// Otherwise it sends no answer, and the background injects the generic path.
export function commandListener({ owner, composing, run, settle = settleComposition }) {
  return (msg, _sender, sendResponse) => {
    if (msg?.type !== 'command') return false;
    let el = null;
    try { el = owner(); } catch {}
    if (!el) return false;
    sendResponse({ handled: true });
    settle(el, { composing: composing() })
      .then(() => run(el))
      .catch((e) => console.warn('[protly] command failed', e));
    return false;
  };
}
```

```js
// Adapter-first routing for Alt+T and the context menu. All Chrome calls are injected so this stays testable.
// Returns 'adapter' | 'generic' | 'unavailable'.
export async function routeCommand({ tabId, frameId = 0, args, sendToTab, injectFile, runGeneric, setBadge, toastInMain }) {
  let answer = null;
  try { answer = await sendToTab(tabId, { type: 'command' }, frameId); } catch {} // no content script there
  if (answer?.handled) return 'adapter';

  try {
    await injectFile(tabId, frameId);
  } catch {
    // chrome:// pages and the Web Store refuse the main frame: badge. A refused cross-origin frame on an ordinary
    // page gets a toast from the main frame instead; the badge would mark the whole tab unavailable.
    if (frameId !== 0) {
      try {
        await injectFile(tabId, 0);
        await toastInMain(tabId, 'protly cannot reach this frame.');
        return 'unavailable';
      } catch {}
    }
    await setBadge(tabId, '!', 'unavailable here');
    return 'unavailable';
  }
  try {
    await runGeneric(tabId, frameId, args);
  } catch (e) {
    console.warn('[protly] generic run failed', e); // the bundle reports its own errors in the page
  }
  return 'generic';
}
```

```js
import { hasHangul, isKoreanOnly, parseLangPrefix } from '../lib/lang.js';

const LETTER = /\p{L}/u;

// What Alt+T does with a text box. A prefix wins whatever the script (design section 6); this is the one place a
// prefix applies to non-Korean text, so "no: ..." in an English box becomes Norwegian. Intended.
export function decideBox(text) {
  const p = parseLangPrefix(text);
  if (p.lang) return p.text.trim() ? { kind: 'translate', lang: p.lang, text: p.text } : { kind: 'none' };
  if (hasHangul(text)) return { kind: 'translate', lang: 'en', text };
  if (LETTER.test(text)) return { kind: 'polish', text };
  return { kind: 'none' };
}

// A selection outside any box goes to Korean.
export function decideSelection(text) {
  const t = (text ?? '').trim();
  if (!t) return 'none';
  if (isKoreanOnly(t)) return 'already-ko';
  return LETTER.test(t) ? 'translate' : 'none';
}
```

```js
const TEXT_TYPES = new Set(['', 'text', 'search', 'email', 'url', 'tel']);
const MAX_DEPTH = 10;

// isContentEditable is the browser's answer; the [contenteditable] walk covers jsdom, which does not implement it.
function isEditable(el) {
  if (el?.isContentEditable === true) return true;
  const c = el?.closest?.('[contenteditable]');
  return !!c && c.getAttribute('contenteditable').toLowerCase() !== 'false';
}

// The focused element, through open shadow roots and same-origin iframes. Cross-origin frames give { el: null }.
export function deepActive(doc) {
  let d = doc;
  let el = d.activeElement;
  for (let i = 0; i < MAX_DEPTH && el; i++) {
    if (el.shadowRoot?.activeElement) { el = el.shadowRoot.activeElement; continue; }
    if (el.tagName !== 'IFRAME' && el.tagName !== 'FRAME') break;
    let inner = null;
    try { inner = el.contentDocument; } catch {}
    if (!inner) return { el: null, doc: d };
    d = inner;
    el = d.activeElement;
  }
  return { el, doc: d };
}

// 'text' | 'contenteditable' | null
export function classify(el) {
  if (!el || !el.tagName) return null;
  if (el.tagName === 'TEXTAREA') return el.readOnly || el.disabled ? null : 'text';
  if (el.tagName === 'INPUT') {
    const type = (el.getAttribute('type') || '').toLowerCase();
    return TEXT_TYPES.has(type) && !el.readOnly && !el.disabled ? 'text' : null;
  }
  return isEditable(el) ? 'contenteditable' : null;
}

function editableRoot(el) {
  let r = el;
  while (r.parentElement && isEditable(r.parentElement)) r = r.parentElement;
  return r;
}

// { el, doc, kind } for the focused text box, or null.
export function findTarget(doc) {
  const { el, doc: d } = deepActive(doc);
  const kind = classify(el);
  if (!kind) return null;
  return { el: kind === 'contenteditable' ? editableRoot(el) : el, doc: d, kind };
}

// The page selection, preferring the focused frame. rect() re-reads the range so a card follows scrolling.
export function selectionInfo(doc) {
  const { doc: inner } = deepActive(doc);
  for (const d of inner === doc ? [doc] : [inner, doc]) {
    const sel = d.getSelection?.();
    const text = sel ? sel.toString() : '';
    if (!text.trim()) continue;
    const range = sel.getRangeAt(0).cloneRange();
    return { doc: d, text, rect: () => { try { return range.getBoundingClientRect(); } catch { return null; } } };
  }
  return { doc, text: '', rect: () => null };
}
```

```js
// Reads and writes a text box on any site. textarea/input: setRangeText plus an input event, which React-style
// controlled inputs notice (their value tracker sees the change). contenteditable: select all and
// execCommand('insertText'), the path the Instagram writer uses, so the editor's own undo and state stay in sync.
export const SELECT_SETTLE_MS = 60; // editors such as Lexical sync their selection on selectionchange

const norm = (s) => (s ?? '').replace(/\s+/g, ' ').trim();

export function readBox(t) {
  if (t.kind === 'text') return t.el.value;
  return (t.el.innerText ?? t.el.textContent ?? '').replace(/\n$/, '');
}

function setValue(el, text) {
  try {
    el.setRangeText(text, 0, el.value.length, 'end');
  } catch {
    // email inputs have no selection API: use the native setter so frameworks still see a change
    const proto = Object.getPrototypeOf(el);
    Object.getOwnPropertyDescriptor(proto, 'value').set.call(el, text);
  }
  const win = el.ownerDocument.defaultView;
  const Ev = win?.InputEvent || win?.Event;
  el.dispatchEvent(new Ev('input', { bubbles: true, inputType: 'insertReplacementText', data: text }));
}

// true only when the box ends up holding text (whitespace-normalized). The caller restores on false.
export async function writeBox(t, text, { settleMs = SELECT_SETTLE_MS } = {}) {
  const { el } = t;
  if (!el.isConnected) return false;
  el.focus();
  if (t.kind === 'text') {
    setValue(el, text);
  } else {
    el.ownerDocument.getSelection().selectAllChildren(el);
    await new Promise((r) => setTimeout(r, settleMs));
    if (!el.isConnected) return false;
    el.focus();
    el.ownerDocument.execCommand('insertText', false, text);
  }
  return norm(readBox(t)) === norm(text);
}
```

```js
import { createCard } from '../ui/card.js';
import { showToast } from '../ui/toast.js';
import { errorText, GLOBAL_KINDS } from '../ui/errors.js';
import { commitByRefocus, nextFrame, settleComposition } from '../lib/ime.js';
import { decideBox, decideSelection } from './decide.js';
import { findTarget, selectionInfo } from './target.js';
import { readBox, writeBox } from './writer.js';

const norm = (s) => (s ?? '').replace(/\s+/g, ' ').trim();
const NOTHING = 'Put the cursor in a text box or select text.';
const CORNER = { top: 16, bottom: 16, left: 16, right: 16, width: 0, height: 0, x: 16, y: 16 };

export async function defaultAsk(msg) {
  let r;
  try {
    r = await chrome.runtime.sendMessage(msg);
  } catch (err) {
    const e = new Error(err?.message || String(err));
    e.kind = /context invalidated|Receiving end does not exist/i.test(e.message) ? 'stale' : 'internal';
    throw e;
  }
  if (!r?.ok) { const e = new Error(r?.error?.message || 'no response'); e.kind = r?.error?.kind; throw e; }
  return r.data;
}

// One per isolated world (run.js keeps it on globalThis.__protly): one card, one set of listeners per document.
export function createInstance({ doc: top = document, fonts = null, ask = defaultAsk, hostname } = {}) {
  const host = () => hostname || top.defaultView?.location?.hostname || '';
  // box: { t, d, card, mode: 'idle'|'working'|'preview', original, shown, lang, hard, reqId, last }
  let box = null;
  let pop = null; // selection popover card
  let seq = 0;
  let composing = false;
  const wired = new WeakSet();

  const toast = (text, opts = {}) => showToast(text, { doc: top, transient: true, ...opts });

  function wire(doc) {
    if (wired.has(doc)) return;
    wired.add(doc);
    if (fonts) addFonts(doc, fonts);
    doc.addEventListener('compositionstart', () => { composing = true; }, true);
    doc.addEventListener('compositionend', () => { composing = false; }, true);
    doc.addEventListener('keydown', onKeyDown, true);
    doc.addEventListener('focusin', onFocusIn, true);
  }

  const inBox = (cur, target) => cur.t.el === target || cur.t.el.contains(target) || target === cur.card.host;

  function onKeyDown(e) {
    if (e.key !== 'Escape' || e.isComposing) return;
    if (box && (box.mode === 'preview' || box.mode === 'working') && inBox(box, e.target)) {
      e.preventDefault();
      e.stopImmediatePropagation();
      if (box.mode === 'working') cancel(box); else undo();
      return;
    }
    if (pop) { pop.hide(); pop = null; } // the page still gets its Esc
  }

  // Focus moved elsewhere: the preview is accepted as it is and the card closes.
  function onFocusIn(e) {
    if (box?.mode === 'preview' && !inBox(box, e.target)) close();
  }

  function close() {
    if (!box) return;
    box.reqId = 0;
    box.card.hide();
    box = null;
  }

  const actionsFor = (cur) => (cur.mode === 'preview'
    ? [{ label: 'Opus', onClick: () => rerun({ hard: true }) }, { label: 'Undo', onClick: () => undo() }]
    : [{ label: 'Close', onClick: () => close() }]);

  function showPreview(cur) {
    const polish = cur.d.kind === 'polish';
    cur.card.preview({
      text: cur.last.back_translation,
      model: cur.last.model, // the card turns the id into 'Sonnet' or 'Opus'
      ...(polish ? {} : { lang: cur.lang, onLang: (code) => rerun({ lang: code }) }),
      actions: actionsFor(cur),
      hints: 'Esc undo',
    });
  }

  function showError(cur, e) {
    const text = errorText(e);
    cur.card.message(text, { error: true, actions: actionsFor(cur) });
    if (GLOBAL_KINDS.has(e?.kind)) showToast(text, { doc: top, error: true });
  }

  function cancel(cur) {
    if (box !== cur || cur.mode !== 'working') return;
    cur.reqId = 0; // the result, when it arrives, is dropped
    cur.mode = cur.prev;
    if (cur.mode === 'preview') showPreview(cur); else close();
  }

  async function request(cur) {
    const reqId = ++seq;
    cur.reqId = reqId;
    cur.prev = cur.mode;
    cur.mode = 'working';
    const polish = cur.d.kind === 'polish';
    cur.card.working(`${polish ? 'Polishing' : 'Translating'}${cur.hard ? ' with Opus' : ''}`, { onCancel: () => cancel(cur) });
    const before = readBox(cur.t); // what the box must still hold when the result lands
    const live = () => box === cur && cur.reqId === reqId;
    let r;
    try {
      r = polish
        ? await ask({ type: 'polish', text: cur.d.text, profile: cur.hard ? 'hard' : 'polish' })
        : await ask({ type: 'box', text: cur.d.text, lang: cur.lang, profile: cur.hard ? 'hard' : 'outgoing', hostname: host() });
    } catch (e) {
      if (!live()) return;
      cur.mode = cur.prev;
      showError(cur, e);
      return;
    }
    if (!live()) return;
    if (norm(readBox(cur.t)) !== norm(before)) {
      cur.mode = cur.prev;
      cur.card.message('The text changed while translating, so the result was dropped.', { error: true, actions: actionsFor(cur) });
      return;
    }
    if (composing) await settleComposition(cur.t.el, { composing: true }); // never write into an open composition
    if (!live()) return;
    if (!(await writeBox(cur.t, r.translation))) {
      const back = norm(readBox(cur.t)) === norm(before) || (await writeBox(cur.t, before));
      cur.mode = cur.prev;
      cur.card.message(back
        ? 'Could not write into this box. Nothing was changed.'
        : 'Could not write into this box. Check the text: Ctrl+Z may bring it back.', { error: true, actions: actionsFor(cur) });
      return;
    }
    if (!live()) return;
    Object.assign(cur, { mode: 'preview', shown: r.translation, last: r, lang: polish ? null : (r.lang ?? cur.lang) });
    showPreview(cur);
  }

  async function rerun({ hard = box?.hard, lang = box?.lang, force = false } = {}) {
    const cur = box;
    if (!cur || cur.mode !== 'preview') return;
    if (!force && norm(readBox(cur.t)) !== norm(cur.shown)) {
      cur.card.message('You edited the text. Running again replaces your edit.', {
        actions: [
          { label: 'Replace anyway', onClick: () => rerun({ hard, lang, force: true }) },
          { label: 'Keep my edit', onClick: () => showPreview(cur) },
          { label: 'Undo', onClick: () => undo() },
        ],
      });
      return;
    }
    Object.assign(cur, { hard, lang });
    await request(cur);
  }

  async function undo() {
    const cur = box;
    if (!cur) return;
    close();
    if (norm(readBox(cur.t)) !== norm(cur.original) && !(await writeBox(cur.t, cur.original))) {
      toast('Could not restore the original text. Ctrl+Z may bring it back.', { error: true });
    }
  }

  async function doBox(t) {
    wire(t.doc);
    commitByRefocus(t.el); // injected after the fact: commit any open composition before reading
    await nextFrame();
    const original = readBox(t);
    const d = decideBox(original);
    if (d.kind === 'none') { toast('Nothing to translate or polish in this box.'); return; }
    close();
    const card = createCard({ doc: t.doc, place: { float: () => t.el.getBoundingClientRect() } });
    box = { t, d, card, mode: 'idle', prev: 'idle', original, shown: null, lang: d.lang ?? null, hard: false, reqId: 0, last: null };
    await request(box);
  }

  async function doSelection(text, sel) {
    const kind = decideSelection(text);
    if (kind === 'already-ko') { toast('Already Korean.'); return; }
    if (kind === 'none') { toast(NOTHING); return; }
    const doc = sel?.text.trim() ? sel.doc : top;
    wire(doc);
    pop?.hide();
    const at = () => { const r = sel?.rect(); return r && (r.width || r.height) ? r : CORNER; };
    const card = createCard({ doc, place: { float: at } });
    pop = card;
    const done = () => { card.hide(); if (pop === card) pop = null; };
    card.working('Translating', { onCancel: done });
    try {
      const r = await ask({ type: 'selection', text });
      if (pop !== card) return;
      card.message(r.translation, {
        actions: [{ label: 'Close', onClick: done }], // the text is selectable; no Copy button
      });
    } catch (e) {
      if (pop !== card) return;
      card.message(errorText(e), { error: true, actions: [{ label: 'Close', onClick: done }] });
      if (GLOBAL_KINDS.has(e?.kind)) showToast(errorText(e), { doc: top, error: true });
    }
  }

  // args: { source: 'command' | 'menu-selection' | 'menu-editable', selectionText? }
  async function run(args = {}) {
    try {
      wire(top);
      if (args.source === 'menu-selection') {
        const sel = selectionInfo(top);
        await doSelection(args.selectionText || sel.text, sel);
        return;
      }
      const t = findTarget(top);
      const same = box && (!t || t.el === box.t.el);
      if (same && box.mode === 'working') return; // one request at a time
      if (same && box.mode === 'preview' && args.source === 'command') { await rerun({ hard: true }); return; }
      if (t) { await doBox(t); return; }
      const sel = selectionInfo(top);
      if (sel.text.trim()) { await doSelection(sel.text, sel); return; }
      toast(NOTHING);
    } catch (e) {
      console.warn('[protly] run failed', e);
      toast(errorText(e), { error: true });
    }
  }

  return { run, toast: (text) => showToast(text, { doc: top, error: true }) };
}
```
